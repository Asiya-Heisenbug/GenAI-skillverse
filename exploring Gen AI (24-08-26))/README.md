
# SKILLVERSE – AI Tool Exploration

This document contains the hands-on exploration of three Generative AI tools: **Ideogram, OpenArt AI, and Meshy AI**.

### Tools Explored

* **Ideogram** – AI image generation, typography, creative visuals, and prompt experimentation.
* **OpenArt AI** – AI image generation using different models, styles, and detailed prompts.
* **Meshy AI** – AI-powered 3D model generation, rigging, motion application, and animation.

### Purpose

The objective of this exploration was to understand how different Generative AI tools work in practice, experiment with prompt engineering, and observe how AI can be used for **2D image creation, creative design, 3D modeling, rigging, and animation**.

### Contents

The document includes:

* Tool introduction and features
* Prompt experiments
* Generated outputs
* Observations and key learnings
* Applications and use cases
* Screenshots/evidence
* Final Meshy AI animation video
